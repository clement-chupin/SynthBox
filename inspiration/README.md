# Inspiration

Ce dossier rassemble de la documentation de recherche sur des groovebox/synthés du
commerce — **pas pour copier**, mais pour comprendre ce qui rend leurs workflows bons et
en tirer des idées adaptées aux contraintes matérielles de GrvEP (petit écran OLED sans
tactile, grille de touches 4×8, 1 joystick, 7 pots, 4 boutons).

Chaque document couvre : le paradigme de séquençage, comment le sound-design/les effets
sont gérés avec peu de contrôles, la synchro/le chaînage de patterns, les idées d'UI/UX
marquantes, et se termine par une section « idées pour GrvEP » qui traduit les concepts
généraux en pistes concrètes exploitables sur ce matériel.

## Sommaire

- [teenage-engineering.md](teenage-engineering.md) — Pocket Operators, OP-1/OP-1 Field, OP-Z, EP-133 K.O. II.
- [korg.md](korg.md) — série Volca, Electribe, NTS-1.
- [this-is-noise.md](this-is-noise.md) — this.is.NOISE inc. : NM2, LC-1X+, et surtout Gamma
  (synthé pensé pour les non-musiciens — split accords/mélodie, gamme toujours verrouillée,
  joystick comme sélecteur de variations plutôt que balayage continu).

Ce dossier est un point de départ pour de futures sessions de développement — à
consulter avant d'attaquer une nouvelle fonctionnalité de séquençage/effets/génératif.
